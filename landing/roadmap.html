HELIXBOX · HOW IT WORKS

Same project.
Another screen.

Your phone controls the workspace. Your laptop does the work.

Data Flow

1. Pair your laptop
Run npx helixbox-cli in your project and scan the QR code in the Android app.

2. Open your workspace
Browse files, follow logs, inspect Git changes, and use basic workspace controls for free. The project stays on the laptop.

3. Start an agent session
Approve $0.25 USDC for one hour or $2 USDC for seven days in Pera Wallet. HelixBox verifies Algorand MainNet settlement before activating access.

4. Keep working
Ask agent questions, run tests, and review patches during the active session without paying separately for each prompt. The seven-day pass has fair-use limits; model and API costs remain separate.
