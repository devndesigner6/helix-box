BEFORE YOU START

A few good questions.

Does my laptop need to stay on?

Yes. HelixBox connects to the workspace running on your laptop. Keep the laptop awake, the CLI running, and the internet connection available.

What can I use for free?

Pairing and basic workspace controls are free. Paid sessions unlock agent access for a defined period: $0.25 USDC for one hour or $2 USDC for seven days with fair-use limits.

Which coding agents can I use?

Codex, OpenCode, Claude Code, and Hermes are supported. Install and authenticate their CLIs on the paired laptop. Availability in the app comes from that laptop’s reported CLI status.

Does the session price include model or API costs?

No. The payment covers HelixBox agent-session access. Your agent provider’s subscription and API billing are separate. The seven-day pass is subject to fair-use limits.

How do I pay for an agent session?

Start a session from the app, open checkout, and approve the USDC payment in Pera Wallet. HelixBox checks settlement on Algorand MainNet before activating your access.

Can I return to the same workspace?

Use the saved connection or Past Sessions when the laptop session is still valid. If the laptop session has ended, run the CLI and use the explicit new-session flow to pair again.

Is HelixBox available on iOS?

The current public build is an Android APK available through GitHub Releases. The source code and setup instructions are available on GitHub.
