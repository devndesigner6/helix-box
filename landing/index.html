BEFORE YOU START

A few good questions.

Does my laptop need to stay on?

Yes. HelixBox connects to the workspace running on your laptop. Keep the laptop awake, the CLI running, and the internet connection available.

What can I use for free?

Pairing, workspace controls and access to coding agents already installed on your laptop are free. Their provider subscriptions remain separate. Only optional model calls through HelixBox are paid.

Which coding agents can I use?

Codex, OpenCode, Claude Code, and Hermes are supported. Install and authenticate their CLIs on the paired laptop. Availability in the app comes from that laptop’s reported CLI status.

What does a model-call quote cover?

One bounded chat, image or speech request to the quoted model. Availability and price are checked before purchase; a catalog listing alone does not guarantee a payable call. A failed generation is not charged. The complete result is released after the x402 payment is accepted. This does not buy unlimited coding-agent usage.

How do agents pay without my wallet key?

You approve the allowed models, per-call cap, total budget, call count, and expiry. The agent discovers a model and requests a quote. Spending must fit your approved policy; otherwise it needs new approval. Stellar x402 uses Soroban authorization signing with a compatible wallet, and a facilitator verifies and settles the USDC payment. x402 itself does not grant an agent unrestricted access to your funds.

Can I return to the same workspace?

Use the saved connection or Past Sessions when the laptop session is still valid. If the laptop session has ended, run the CLI and use the explicit new-session flow to pair again.

Is HelixBox available on iOS?

This version targets Android. Use this repository’s Releases page for APK downloads and its build instructions to build from source. An iOS release is not available yet.
